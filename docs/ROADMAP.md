# ROADMAP

**このリポジトリで次に何を実装するかを決める唯一のバックログ。** `/evolve` ループが毎サイクル
最初に読み、ここから 1 件選んで実装する。

**要望・機能追加・不具合は `docs/REQUESTS.md`（受信箱）に自由記述で書く。** ループが毎周それを
読んでこの表へ反映するので、**このファイルを人間が直接編集する必要はない**。書き込むのがループ
だけであれば、サイクルが完了行を消すのと人間の編集が同じ行を取り合うこともない。

## 運用ルール

1. **上から順に着手する。** セクション順（バグ修正 → 高 → 中 → 低）、セクション内は表の上から。
   飛ばすのは「サイズ **L**」「`blocked`」「前提が未達」のときだけで、その理由を報告に書く。
2. **完了したら行をこの表から消し、`docs/roadmap-done.md` に 1 行足す。** 両方に残さない。
3. **`blocked` は「やらないと決めた」か「今は着手できない」。** 必ずメモ欄に理由を書く。
   `blocked` の行はループが勝手に `todo` へ戻さない — 戻すのは人間だけ。
4. **サイズ L はそのまま着手禁止。** その周は「L を S/M へ分割して表を書き換えるだけ」で終わらせ、
   実装は次の周に回す。分割の前に、メモ欄にリンクした `docs/investigations/STUDY_*.md` を読む。
5. **バグ・要望の入口は `docs/REQUESTS.md`。** GitHub issue は使わない（双方向の同期コストに
   見合わないため）。受信箱は人間が書きループが消すだけの一方向なので、その同期は要らない。
   長い診断が要るものだけ `docs/investigations/BUG_*.md` を起こし、ここからリンクする。
6. **このリポジトリで実装しないもの**は「見送り (blocked)」節にある。ループはそこへ着手しないだけ
   でなく、**関連する機能を新たに提案することもしない**。

## 凡例

| サイズ | 目安 | 意味 |
|---|---|---|
| **S** | 1 時間相当 | 1 ファイル〜数ファイルの局所的な変更。設計判断がほぼ要らない |
| **M** | 半日相当 | 複数レイヤに跨るが、既存の型と画面の枠内に収まる |
| **L** | 要分割 | 画面 1 つ分以上、または新しい抽象が要る。**そのまま着手しない** |

## 見送り (blocked)

**ここはループが着手しない。提案もしない。**

| 状態 | 項目 | サイズ | メモ |
|---|---|---|---|
| blocked | 汎用の「もとに戻す」（undo） | L | **スコープ外。**「優先度: 中」の**「移動・削除トーストの『もとに戻す』」はこれとは別物**で、履歴を持たず直前の 1 操作だけを戻すもの。混同しないこと。 MEGA にネイティブな undo が無く、全操作に手書きの逆操作（rename↔rename / rubbish→戻す / copy→delete / create→delete）と、全変更経路への記録フック、履歴破棄のポリシーが要る。Phase 23（コピー／カット／貼り付け）と同じ要望から出たが、そこで落とした。→ `docs/PROGRESS.md` の「Phases 20a–23 — the detail pass」前文。`CLAUDE.md` のスコープ宣言もこれに従う |
| blocked | ローカルとの完全な双方向同期 | L | **スコープ外。** このアプリは同期クライアントではない（フォルダを開いたときの単発バックグラウンド更新だけ） |
| blocked | タブをウィンドウの外へ切り離す | L | **スコープ外。** → `docs/investigations/STUDY_TITLEBAR_TABS.md` |
| blocked | プラグイン対応 | L | **保留（スコープ外ではない）。** 現状未知の部分が多く大幅な機能改修が予想されるため、十分な仕様が固まるまで着手しない。中身: コンテキストメニュー項目の追加・独自プレビュー・設定画面の追加を外部から。トースト／ダイアログ／ファイル更新の API 公開も要る。動機は WD Tagger による自動タグ付けで、ファイラーのドメインから外れるためデフォルト同梱にしたくない、というもの |
| blocked | ローカルフォルダとの紐づけ | L | **保留（スコープ外ではない）。** 仕様が未確定で、決まらないと何も始められない。中身: 「ローカルファイルの場所を開く」導線。MEGA 上のフォルダとローカルの対応をユーザーに設定させる必要がある（MEGAsync の設定を読むのは多分無理） |
